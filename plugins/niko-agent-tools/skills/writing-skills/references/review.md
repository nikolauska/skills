# Reviewing skills

Read the skill and only the resources and metadata relevant to the requested critique. Check whether its description selects the intended task without claiming unrelated work, whether the root loads only necessary guidance, and whether consequential actions have clear boundaries without unnecessary approval gates. Check local links and use installed validators when useful; do not run untrusted target scripts or install dependencies.

Report evidence-backed issues with locations and the smallest actionable fixes. Distinguish observed failures from unverified concerns. Do not impose a score or report template unless requested; for a weighted grade use [scoring guidance](scoring.md). Remain read-only even when a fix is obvious.
