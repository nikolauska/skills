# Optional skill scoring

Use only when the user asks for a weighted score or grade. Evaluate the actual skill and relevant resources, cite evidence for deductions, and distinguish unverified concerns from observed problems. Score each dimension from 1 to 5 (half points allowed):

| Dimension | Weight | Consider |
| --- | ---: | --- |
| Specification and metadata | 20% | Valid frontmatter, name matching directory, accurate description and metadata |
| Trigger precision | 15% | Specific what/when, clear scope boundaries |
| Workflow quality | 20% | Actionable guidance with appropriate freedom and decisions |
| Progressive disclosure | 15% | Concise core, useful resources loaded only when needed |
| Safety | 15% | Boundaries for secrets, destructive operations, and external effects |
| Robustness | 10% | Meaningful checks and handling of likely failure cases |
| Portability | 5% | Capability language without unnecessary vendor lock-in |

Weighted score (out of 5) = sum of each dimension's score × its weight. Grade bands: A ≥ 4.5; B ≥ 3.5; C ≥ 2.5; D ≥ 1.5; F < 1.5. Include dimension scores and actionable findings. These bands describe a requested review, not a target or completion gate for writing a skill.
